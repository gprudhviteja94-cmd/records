  • IntelliJ run configuration issues Walkthrough of IntelliJ steps:
    
    • Right-click current file → Run/Run Configuration → Edit Configuration.
    • Locate the application configuration (spring-boot / application entry).
    • Ensure correct Java version is selected (Java 21 was shown as incorrect in one view).
    • Select the correct application main class; if it doesn’t appear, IntelliJ is not detecting the main method.
    • Use Modify Options → Add VM options / Active profile as needed.
    • If run configuration can't find the main class, try manually typing the class name or recreate the configuration.
    • For spring-related applications, ensure Spring Boot main class is recognized (it should scan for main annotation or public static void main).

  • Specific configuration troubleshooting The participant could not get the main class auto-detected. The helper suggested:

    • Copy-paste of certain arguments was discussed but blocked due to secret values — those will be delivered via secure channel (email/Slack).
