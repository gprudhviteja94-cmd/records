📒Meeting Outline

Lumi platform overview and motivation

• Platform history & rationale  
  The team reviewed why Lumi was created: the legacy on-prem platform (Cornerstone) served well but required modernization. Lumi was developed as a next-generation, cloud-native big data ecosystem emphasizing modularity, scalability, autonomy, and self-serve capabilities to meet evolving business and technical needs.

• Core design principles  
  Modularity and scalability as core principles; unified DAO movement framework for ingesting data from multiple internal and external sources; focus on automation for ingestion and transformation; built-in governance and compliance to support enterprise requirements.

• Value proposition  
  Lumi empowers users with self-serve ingestion and automated transformation, easier governance, and faster delivery of analytics/ML capabilities. It intends to reduce manual handoffs and speed migration from on-prem systems.

Lumi core capabilities and functions

• Data movement  
  Covers ingestion, metadata management, and historical data migration. Unified DAO movement framework standardizes how data moves into Lumi.

• Data transformation  
  Lumi offers products (HyperDrive, SchemaFactory, LumiData Transformation (DT) tool) to normalize and prepare data. The platform supports low-code/no-code ETL, enabling users to create their own pipelines and reduce dependency on developers.

• Analytics  
  Integration with BigQuery for large-scale processing and analytics; portal links to analytics tools (BigQuery, Aida, Envision) open in new tabs for seamless workflows.

• AI / ML  
  Lumi supports building dashboards and training ML models for complex queries and pattern detection; provides tools to operationalize models and surface insights for decision-making.

• Portal & UX  
  Lumi Portal is the single point of entry: onboarding, search, activity tracking, user personalization, and user management. Portal includes Lumi Academy (training), support (Slack/email/Lumi ambassadors), and links to documentation (Confluence/Square page).

Access, onboarding, and portal navigation

• Access process  
  Users visit lumi.exp.com, review and agree to the Lumi Usage Policy, then request access/entitlements. Requests require a clear business description and are typically approved within 2–24 hours.

• Portal navigation  
  Home screen top bar navigation with categories/subcategories; Projects → My Projects to view project creations; direct links to external tools; Activity section acts as notifications; unified search provides access to tables, variables, docs, attributes, ownership, security and related metadata.

• Support & learning  
  Lumi Academy for self-paced learning and office hours; contact via Slack channel #Lumi-Engage, email (lumi@aexp.com), and Confluence FAQ pages.

Lumi Usage Policy (overview, scope, roles)

• Purpose of usage policy  
  Defines frameworks, processes, operating principles for onboarding and platform use for valid business purposes; delineates roles/responsibilities; prescribes guidelines for project spaces, monitoring, change management and introducing new functionalities.

• Why it matters  
  Emphasizes data protection, adherence to American Express management policies and tech standards, and clear expectations for roles to maintain data security and platform stability.

• Scope  
  Policy covers: data ingestion, data security (masking, protection), access & privileges, project space enablement, data lifecycle management (E-79 and E-08 referenced), BI tool usage, data sharing/transfers, data quality, and change management.

• Roles & responsibilities  
  • Application Owner (EAM-30): manage source applications and data flows into Lumi, understand business & technical aspects.  
  • Data Ingestion Owner: ensure feeds/tables comply with policy and IDL guidelines; manage changes to ingestion.  
  • EAM 7E Activated Data Steward: own critical data elements (CDEs), define data meaning, lineage, and maintain quality.

• Acknowledgement & compliance  
  Users must read and sign the usage policy via the portal. Policy is accessible in the Useful Links section of Lumi Portal after login.

Lumi data governance/process flow

• Nine core governance modules (Circle of Truth)  
  1. Data ingestion (requesting, gating, approval, ownership)  
  2. Data security (masking, protection)  
  3. Access management (permissions)  
  4. Data quality (roles, CDE remediation)  
  5. Data consumption (analytics & BI)  
  6. Usage monitoring (audit & policy alignment)  
  7. Data sharing (secure transfers, compliance)  
  8. Data lifecycle management (creation → deletion)  
  9. Change management (track/manage changes)

• Auditability  
  Usage monitoring and audit logs are part of compliance and operational oversight.

Data Transformation product (Lumi DT) and migration accelerators

• DT product overview & mission  
  LumiDT is an in-house low-code/no-code data transformation tool allowing users without programming background to design ETL pipelines. Mission: simplify transformation via self-serve UI, accelerators, and cloud-native scalability.

• Key features  
  • Supports 140+ functions and custom functions.  
  • Drag-and-drop UI; flow creation and editing without coding.  
  • Migration accelerators and validators to import existing flows.  
  • Collaborative development (versioning, compare, merge).  
  • Integrations with data ingestion, data quality, security, and governance.

• Architecture & execution flow  
  • Flow created in UI and stored as JSON for two-way compatibility.  
  • Validation and optimization recommendations via validators.  
  • Translator converts flows to BigQuery SQL.  
  • Execution orchestrated by GCP Airflow on Google Cloud Platform.

• Access & pre-reqs  
  Users need access to a GCP project (request DT team for permissions) and Lumi portal access to use DT.

Magellan Accelerator and migration from Cornerstone

• Context  
  Magellan is an on-prem drag-and-drop transformation tool used on Cornerstone. Migrating Magellan maps to Lumi by rewriting would be time-consuming.

• Magellan Accelerator  
  Utility to import Magellan maps into LumiDT to accelerate migration. Steps: Lumi Portal → Data Transformation → Select project → Import Flow → provide details → Save → rendered Lumi flow.

• Limitations / manual touchpoints  
  Accelerators speed migration but manual intervention may be required for data typecasting, automated UDF onboarding, and handling complex ODL scenarios.
