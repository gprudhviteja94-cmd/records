Data Mapping and Framework Compatibility

• Mapping 8-Dimension Checks to Existing DQ Checks  
  The team discussed the need to map the 8-dimension checks (completeness, accuracy, etc.) to existing check types in the DQ framework. Focus is on the "dimension" and "SQL query" columns, ignoring profiling metadata.  
  If the 8-dimension checks do not fit the existing template, they may be onboarded as complex checks or the framework may be modified.  
  Sachin will prepare a report on the analysis for review, followed by a meeting with Rachna to decide next steps.

• Data Migration Considerations  
  Prior to migrating data into Qtrak, the team must ensure SQL queries generated by automation are compatible with the DQ artifacts table and the overall framework. This includes verifying if accuracy checks can be mapped to valid values.
