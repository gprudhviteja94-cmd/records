Data Processing and Workflow Integration

• RRF Request Processing and File Flow
  The discussion clarified the workflow starting from raising a dev RRF request, which is processed by an RA side analyst through the RA tool. The repricing analyst picks the request, generates a claim file, and drops it into the NAS directory. Petal then picks up the claim file, processes it, and sends data to both the legacy SQL server (rsdatabricks) and the dev databricks environment. In the dev environment, the data is processed to generate a P&L file and insert an RPT record into the on-prem dev database to maintain legacy compatibility.

• Access and File Handling on NAS
  It was confirmed that repricing analysts already have access to the NAS drive. The team discussed the possibility of requesting repricing analysts to place files directly on NAS for processing, treating these files as normal claims files to ensure seamless integration into the dev environment.

Data Validation and Issue Resolution

Issues include misaligned columns in competitor analysis tabs and differing metric values. Kevin is personally handling the testing and fixes to ensure 100% match or explainable differences before handing over to the testing team.

• Testing and Sign-off Process
