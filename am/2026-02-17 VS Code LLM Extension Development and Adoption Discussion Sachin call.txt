📒Meeting Outline


VS Code LLM Extension Demo and Architecture

  • Extension overview The presenter (Prithvi) shared a custom VS Code extension project named "extension master 2" (local extension) built to interact with an LLM for automated generation tasks. It is not published to the VS Code Marketplace; it runs locally as a developer extension and can be launched via the VS Code "Extension Development Host" (F5). The extension can be shared as code for others to run locally.

  • How the extension works The extension orchestrates multiple agents (orchestrator agent, LL agent/interpreter agent, etc.). Each agent interacts with an LLM to collectively generate outputs. The example workflow: select an input JSON file → run the plugin to "generate skills" → agents call the chosen LLM(s) and produce outputs (updated JSON, reasoning text, final SQL, etc.).

  • LLM integration The extension uses built-in VS Code LLM integrations (e.g., GitHub Copilot's LLM variants like "Cloud Haiku"). No external LLM installation was required; the extension invokes the LLM available within the environment (similar to how Copilot responds to prompts).

  • Outputs produced The tool is capable of:
    
    • Creating JSON files from inputs
    • Updating existing JSON/tag files
    • Producing explanatory reasoning text for changes
    • Generating final SQL queries The presenter emphasized end-to-end automation potential, including updating tags and producing traceable reasoning.
