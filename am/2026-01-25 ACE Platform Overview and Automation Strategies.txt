📒Meeting Outline


ACE Platform Overview

  • What is ACE ACE (Automation and Case Ecosystem / ACE Studio) is a foundational platform for business workflow automation (process management) and semi-predictable business case management (case management) across Amazon. It supports process, case, and work management, business rule execution (RuleAssist), RPA, process intelligence, and an admin portal (ACE Control Center). ACE emphasizes use of open-source libraries so teams avoid specialized proprietary tool training.

  • ACE Engine (Automation core) ACE Engine is the runtime/controller that takes the designed workflow and automates execution. It drives stepwise process automation, interprets design-time decisions, routes work, and orchestrates tasks (including service, user, and RPA tasks).

  • Automation modalities
    
    • Stepwise BPMN-driven process automation.
    • Business-rule-driven automation via RuleAssist (Drools-backed).
    • Robotic Process Automation (RPA) using Robot Framework to automate web, mainframe, and desktop interactions.


Process Management

  • Definition and capabilities Process management covers design, development, execution, automation, and tracking of workflows. ACE supports BPMN (industry standard) with alternate flows, gateways, human tasks, and robot tasks. Processes can be scheduled or triggered.

  • Sample process discussed Monthly scheduled payment process:
    
    • Step 1: Get payment details (service task).
    • Step 2: Process payment via RPA (robot task).
    • Step 3: Validate payment status (service task).
    • Gateway: On success -> end; on failure -> manual human task to complete payment. Demonstrated handling of pass/fail outputs, alternate flows, and combining RPA + human tasks.


Case Management

  • Definition and when to use Case management (CMMN) is for semi-predictable, non-linear, data-driven business activities where the order of tasks depends on inputs/conditions. Cases support stages, sentries (condition watchers), milestones, subprocess/process tasks, and human tasks. ACE supports CMMN and provides ACE Caselight (low-code/no-code) for simple case types and rapid onboarding.

  • Sample case discussed Credit line application case:
    
    • On case creation, collect applicant details (process/subprocess task) runs automatically (no sentry on that plan item).
    • Case data updates trigger sentries that evaluate conditions (approve/reject).
    • If rejected -> handle rejection stage executes; milestone updates accordingly.
    • If approved -> enter fulfill-application stage; create-account process task may trigger, update case data, then communicate to customer.
    • Milestones track completion state of logical goals; not all plan items must execute for case completion.

  • Clarifications about sentries and subprocesses
    
    • Sentries act like signal/condition checks evaluated when case data is updated.
    • Subprocesses are BPMN processes invoked within a case (or user tasks).


Work Management

  • Definition Work refers to tasks assigned to humans or human-like actors (bots). Work items pause process/case execution until completed or exited. Work management covers assignment, lifecycle tracking, and queuing.

  • Task lifecycle ACE follows OASIS human task lifecycle with selected states: ready, reserved, in progress, suspended variants, completed, exited. Examples discussed:
    
    • Ready -> Reserved (assigned) or Suspended Ready.
    • Reserved -> In Progress (start) or Delegate or Suspended Reserved.
    • In Progress -> Complete, Suspend/Resume, or Exit.
    • SLA handling: interrupting boundary events and SLA routes; breached SLA can release assigned user and return task to work basket for reassignment.

  • Work baskets and worker actions
    
    • Grouping/queuing of tasks.
    • Workers update status (in progress, suspend, complete, exit).
    • Admins can allocate tasks and view/filter by task state.


ACE Studio (Composer) and Tooling

  • Composer features
    
    • Visual designer for BPMN and CMMN models.
    • Save, share, collaborate, publish models.
    • Define inputs/outputs, work baskets, assignments, RPA script references, scheduler for processes.
    • Service catalog for reusable service tasks and RPA scripts.
    • RPA development integrated (Robot Framework used for RPA scripts).

  • Demo highlights
    
    • Building the sample payment process: add service task (get payment details), RPA service task (process payment on portal), validation, gateway to end or manual user task.
    • CMMN modeling: stages, sentries, milestones, process tasks.
    • Publishing models to assets for reuse and sharing across processes.
    • Reusable service tasks allow consistent reuse across multiple processes.


Business Rules (RuleAssist)

  • Purpose Business rules evaluate input data and produce outputs or decisions (e.g., reject applicant under age 18). Useful for validations, eligibility checks, and decision logic.

  • Implementation
    
    • RuleAssist is powered by Drools.
    • Supports Drools native language, decision tables (Excel), and domain-specific languages.
    • Supports rule usage tracking and auditing; rules can be updated without interrupting running processes/cases.


Process Intelligence

  • Purpose Capture and analyze event data to discover process patterns, identify bottlenecks, measure throughput times, and surface optimization opportunities.

  • Capabilities
    
    • Automatic acquisition of process event data across ACE and integrated systems.
    • Discovery, modeling of variants, monitoring and optimization recommendations.
    • Metrics for work distribution, completion times, bottleneck detection.
    • Helps teams prioritize automation or improvements.


ACE Control Center (Admin Portal)

  • Purpose Admin portal to manage processes, cases, rules, scheduling, security, and bulk processing.

  • Key sections
    
    • Process and case instance search and status dashboards (filter by dates, status, process ID, correlation key).
    • Work management: manage work baskets, allocate tasks, filter tasks by lifecycle state.
    • RuleAssist: view deployed business rules, usage metrics, and audit logs.
    • Scheduling: configure and review scheduled processes.
    • Bulk processing: define bulk policies to run processes for bulk datasets.
    • Security: manage access controls for triggering processes, creating cases, and picking up work.
    • Process Intelligence integration (insights dashboards) — deeper dive to be covered in later sessions.


Q&A Highlights

  • Difference between process and case:
    
    • Processes are directed, predictable flows (BPMN).
    • Cases are data-driven, non-linear, and not all plan items must execute (CMMN).

  • Sentries behavior:
    
    • Sentries evaluate on case data updates (signal-like).

  • Subprocesses in cases:
    
    • Can invoke BPMN subprocesses or user/human tasks.

  • RPA scripting language:
    
    • Robot Framework is used.

  • SLA/time boundaries for human tasks:
    
    • Use interrupting boundary events and SLA routes; on breach, task can be released back to basket for reassignment.


📋Overview

  • ACE is a unified platform for process automation, case management, RPA, business rules, work management, process intelligence, and admin operations.
  • ACE Engine automates BPMN-defined processes and orchestrates tasks including RPA.
  • Case management (CMMN) handles non-linear, data-driven business cases; Caselight provides low-code/no-code for simple cases.
  • RuleAssist (Drools) enables business-rule driven automation and decisioning; rules are auditable and updatable without downtime.
  • Work management supports OASIS-based task lifecycle, work baskets, SLAs, and task assignment/delegation.
  • ACE Studio Composer provides an accessible UI to design BPMN/CMMN, build RPA scripts, and publish reusable service tasks.
  • ACE Control Center centralizes admin tasks: process/case monitoring, work allocation, scheduling, rule management, bulk processing, security, and process intelligence insights.
  • Process Intelligence captures events to reveal bottlenecks and optimization opportunities.
