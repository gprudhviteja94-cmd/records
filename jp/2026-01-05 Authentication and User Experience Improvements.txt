📒Meeting Outline

Authentication and Login Flow

• login button necessity
  Team discussed skipping the explicit “Sign in” button when users arrive via shared URL. Expectation is to leverage Microsoft Authenticator for seamless SSO without an extra click.
• organizational standards
  Question raised whether Optum has standards/guidelines for auto sign-in. No known standard was identified; consensus formed that absence of a restriction allows auto-login.
• precedent in CPM
  Reference made to CPM flow where users are taken directly into the app without a login button. Stakeholders prefer replicating this behavior if feasible to reduce friction.

User Story and UI Behavior

• UI vs edit values
  Manmeet referenced a user story to clarify/display “UI value” vs “edit value” in the capability; planned to demo after pulling it up in Rally.
• ownership and follow-up
  Manmeet to present details; Speaker 3 to coordinate confirmation that the story covers the requested behavior.

Release Planning, Milestones, and Branching

• milestone tagging
  Request to add milestones to stories currently in the sprint to avoid ambiguity when merging into the sprint branch, especially if certain items won’t ship in the Jan 13 release.
• inclusion in 13th release
  Agreement that if stories are completed in time, they can be included in the 13th release; otherwise they remain in UAT and not production. After first version release, formal milestone/versioning discipline will be enforced.
• code freeze/branch cut
  Recommendation to establish an earlier code freeze or branch cut for the first version (e.g., by the 10th) to stop ongoing merges and stabilize for release.
