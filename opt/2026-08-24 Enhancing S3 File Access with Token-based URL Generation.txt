📒Meeting Outline

Enhancing Pre-signed URL Usage for S3 File Access

• Current Limitations of Amazon Pre-signed URLs  
  The team discussed the inherent limitation of Amazon pre-signed URLs, which expire after a maximum of seven days. This is problematic as business requirements often demand links valid for longer periods, such as three months or one year. Additionally, sharing encrypted files via these URLs requires a controller to decrypt files on download, which raises security vulnerability flags due to passing URLs in the API.

• Proposed Token-based URL Generation Solution  
  To overcome these limitations, a custom token-based URL generation handler was developed. Instead of relying on Amazon’s pre-signed URLs, this handler creates tokens encoded in base64 or base32 that include configurable expiry durations (e.g., 7 days to 365 days). The token validates access and expiry, allowing secure and flexible link generation that supports encrypted file downloads without exposing direct URLs.

• Implementation Details and Configuration  
  The handler is integrated at the tenancy level with configurable properties such as secret keys, process names, S3 access keys, endpoints, bucket names, and expiry settings. The token validation occurs in a controller that decrypts files on demand and serves them securely. The downloadable URL generated can be embedded in emails or templates for stakeholders to access reports anytime within the token validity period.

• Demonstration and Code Walkthrough  
  A live demonstration showed how the token-based URLs are generated and validated. The team reviewed the code structure, including methods to generate URLs, handle file uploads with encryption, and validate tokens during download requests. The solution is already deployed in production for daily reports with extended expiry (up to 365 days), successfully mitigating previous security vulnerabilities.

• Adoption and Future Use  
  The solution is open for use across various projects and tenancies. It addresses flagged security issues and meets business needs for longer-lasting, secure download links. Team members were encouraged to review the shared repository and documentation to implement this approach in their respective use cases.

📋Overview

• Amazon pre-signed URLs have a fixed maximum expiry of seven days, which does not meet longer-term business requirements.
